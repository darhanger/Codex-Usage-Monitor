# Настройка

## Расположение настроек

Состояние интерфейса хранится в:

```text
%APPDATA%\CodexUsageMonitor\settings.json
```

Если `APPDATA` определить невозможно, реализация использует `CodexUsageMonitor\settings.json` относительно рабочего каталога. В обычной пользовательской сессии Windows переменная `APPDATA` должна присутствовать.

Файл создаётся при изменении сохраняемой настройки меню или позиции. Перед ручным редактированием закройте приложение: последующая запись из процесса заменяет весь JSON. Сохранение неизвестных JSON-полей не гарантируется.

## Сохраняемые поля

| Поле | Тип | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `tray_offset` | целое | `0` | Горизонтальное смещение от области уведомлений выбранной панели задач |
| `taskbar_index` | неотрицательное целое | `0` | Индекс панели задач после стабильной сортировки по позиции на экране |
| `poll_interval_ms` | неотрицательное целое | `900000` | Обычный интервал опроса провайдеров в миллисекундах |
| `language` | строка или `null` | `null` | Явный код языка; `null` включает определение языка Windows |
| `last_update_check_unix` | целое или `null` | `null` | Время последней завершённой проверки обновления в Unix seconds |
| `widget_visible` | boolean | `true` | Сохранённая видимость виджета |
| `show_claude_code` | boolean | `false` | Показывать и опрашивать Claude Code |
| `show_codex` | boolean | `true` | Показывать и опрашивать Codex |
| `show_antigravity` | boolean | `false` | Показывать и опрашивать Google Antigravity |

Если после загрузки все три провайдера выключены, приложение включает Codex. Некорректный JSON заменяется набором значений по умолчанию. Для поддерживаемых значений используйте меню: числовые поля из JSON десериализуются без отдельной нормализации диапазона.

## Настройки меню

Нажмите правой кнопкой на виджет или любой индикатор провайдера в трее.

- **Обновить** запускает немедленный фоновый опрос и разрешает повторно показать актуальное уведомление об авторизации.
- **Частота обновления** выбирает 1 минуту (`60000`), 5 минут (`300000`), 15 минут (`900000`) или 1 час (`3600000`).
- **Модели** независимо включает Claude Code, Codex и Antigravity, не позволяя отключить последний активный провайдер.
- **Настройки > Запускать вместе с Windows** обновляет `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\CodexUsageMonitor` текущим путём EXE.
- **Настройки > Сбросить позицию** возвращает стандартное смещение на панели задач.
- **Настройки > Язык** выбирает системный или явно указанный поддерживаемый язык.
- Пункт с номером версии проверяет обновления, применяет доступное portable-обновление либо передаёт управление WinGet.
- **Показывать виджет** сохраняет видимость. При скрытом виджете иконка в трее остаётся доступной.

Виджет также можно перетаскивать. `taskbar_index` меняется при переносе на другую панель задач, а `tray_offset` хранит ограниченную позицию перед областью уведомлений.

## Языки

Сохраняемые явные коды: `en`, `nl`, `es`, `fr`, `de`, `ja`, `ko`, `zh-TW`, `zh-CN`, `ru` и `pt-BR`. Без override приложение последовательно проверяет предпочитаемые языки интерфейса Windows, основной язык UI и locale.

## Авторизация провайдеров

### Codex

- Установите актуальный отдельный Codex CLI либо официальное расширение OpenAI с Windows-исполняемым файлом Codex.
- Поддерживаются каталоги расширений VS Code, VS Code Insiders, VS Code OSS, Cursor и Windsurf, а также `VSCODE_EXTENSIONS` и `VSCODE_PORTABLE`.
- Выполните вход через учётную запись ChatGPT в официальном интерфейсе или CLI Codex. Режим только с API-ключом не предоставляет нужные виджету окна квот аккаунта.
- Монитор запускает официальный CLI App Server и не разбирает bearer-токен Codex. Метаданные `%CODEX_HOME%\auth.json` или `%USERPROFILE%\.codex\auth.json` используются только для обнаружения изменения входа.

### Claude Code

- Выполните вход в Claude Code в Windows, WSL или обеих средах.
- Windows-данные читаются из `%USERPROFILE%\.claude\.credentials.json`.
- Каждый установленный дистрибутив WSL может проверяться на `~/.claude/.credentials.json`; Windows имеет приоритет, затем используется порядок перечисления WSL.
- Файл должен содержать объект `claudeAiOauth` с access token. Отдельного поля ручного API-ключа в мониторе нет.
- При истёкших OAuth-данных монитор может запустить соответствующий Claude CLI с минимальным запросом, чтобы CLI самостоятельно обновил credentials.

### Google Antigravity

- Выполните вход в Google Antigravity в Windows.
- Монитор читает generic credential `gemini:antigravity` из Диспетчера учётных данных Windows.
- JSON учётных данных должен содержать `token.access_token`.
- Переопределения файла или токена через `settings.json` нет.

Источники учётных данных читаются только для включённых провайдеров. Не копируйте их содержимое в файл настроек.

## Опрос и повторные попытки

Выбранный интервал управляет обычным опросом. Операции выполняются вне UI thread. Включённые провайдеры вызываются последовательно и возвращают независимые результаты и ошибки.

- Временные ошибки запросов используют экспоненциальную задержку от 30 секунд до выбранного обычного интервала.
- Ошибки авторизации и отсутствующие credentials показывают не более одного уведомления на провайдера за один эпизод и ждут последующего изменения данных либо ручного обновления.
- Обратный отсчёт имеет отдельный таймер и не выполняет сетевые запросы.
- После наступления времени сброса назначается более быстрый опрос для замены устаревшей квоты.

## Виджет, панели задач, тема и автозапуск

Выбранная панель задач и смещение сохраняются. Панели перечисляются по положению на экране, поэтому после изменения топологии старый индекс может соответствовать другому физическому дисплею. Используйте **Сбросить позицию** или перетащите виджет заново.

Виджет отслеживает DPI каждого монитора. Цвета темы определяются `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize\SystemUsesLightTheme`; отдельной темы приложения нет.

Автозапуск считается включённым только при точном совпадении значения реестра с текущим EXE. После переноса portable-файла старое значение намеренно считается выключенным, пока опция не включена снова из нового расположения.

## Настройка обновлений

Автоматическая проверка выполняется не чаще одного раза в 24 часа; ручная проверка из меню может запускаться раньше. `last_update_check_unix` хранит время попытки. GitHub-репозиторий определяется при компиляции из `package.repository` в `Cargo.toml`.

- Portable используется вне известных каталогов пакетов WinGet. Каталог должен быть доступен для записи, а последний Release обязан содержать `codex-usage-monitor.exe`.
- WinGet выбирается для EXE в пользовательских или системных каталогах WinGet `Packages` и выполняет `winget upgrade --id DarhangeR.CodexUsageMonitor --exact`.

Ручного переключателя канала нет: канал определяется путём текущего EXE.

## Переменные proxy

Нативный HTTP-клиент поддерживает proxy из окружения. В зависимости от URL переменные `HTTPS_PROXY`, `HTTP_PROXY` или `ALL_PROXY` могут влиять на Claude Code, Antigravity, проверку GitHub и portable-загрузки. Дочерние CLI наследуют окружение, если сам CLI не применяет другие правила.

Не добавляйте credentials proxy в диагностику или Issues. Proxy способен наблюдать или изменять трафик провайдера и обновлений в пределах доверия TLS на компьютере, поэтому используйте только доверенный сервер и цепочку сертификатов.

## Диагностика

Диагностика не является сохраняемой настройкой меню. Запустите процесс явно:

```powershell
.\codex-usage-monitor.exe --diagnose
```

Файл `%TEMP%\codex-usage-monitor.log` очищается при каждом диагностическом запуске. Он может содержать обнаруженные пути EXE, пути к credential-файлам, имена дистрибутивов WSL, координаты панели задач и категории ошибок. Перед публикацией его необходимо очистить, хотя значения токенов намеренно не логируются.
