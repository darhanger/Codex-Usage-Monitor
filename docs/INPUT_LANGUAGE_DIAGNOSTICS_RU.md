# Диагностика исчезающей раскладки

Код приложения не вызывает API загрузки, активации или выгрузки раскладок. Поэтому исчезновение украинского языка из переключателя пока нельзя считать доказанным изменением конфигурации Windows. Для редкого случая нужно сравнить состояние до и после сбоя.

1. Закройте уже запущенный монитор через его меню и запустите проверяемую сборку с параметром `--diagnose`. Приложение пишет `%TEMP%\codex-usage-monitor.log`.
2. До запуска, после запуска и непосредственно при исчезновении языка выполните `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\check-input-languages.ps1` из корня репозитория. Сохраните три вывода.
3. При сбое проверьте `Win+Space` в обычном текстовом поле и зафиксируйте, есть ли там украинский язык. Снимите скриншот области уведомлений и запишите, было ли открыто контекстное меню монитора.
4. Приложите лог и три снимка состояния. Строки `input-state` содержат список загруженных HKL и HKL активного окна; строки `taskbar space unavailable` показывают геометрию, из-за которой индикатор скрывается.

`Get-WinUserLanguageList` отражает сохранённые настройки пользователя. `GetKeyboardLayoutList` показывает набор загруженных раскладок в момент измерения. Если оба списка содержат украинский, а переключатель её не показывает, проблема в представлении Shell или TSF. Если язык исчез из одного из списков, потребуется отдельная проверка источника изменения; монитор только читает эти значения.
